# Atraso máximo de tarefa — Sprint 2

## Objetivo

Registrar o atraso máximo permitido para a conclusão de uma tarefa.

## Alteração

## Limitação

- A migration não define valor padrão, obrigatoriedade ou restrição de faixa para a coluna.
